## 多格式协作预览（2026-09-17）

## 同文件共享对话上下文（2026-09-17）

此规则替代此前“从分享页进入空对话”的交互：无论从历史对话还是分享页的评论进入，都展示同一文件的初始上下文与后续消息。五种格式共用消息逻辑，每个格式示例独立保存记录。

- 用户消息采用深绿色圆角气泡，显示发送老师的小标签；发送人随消息保存，与被引用评论的作者区分。
- 注释仍先带入输入框，允许补充要求后发送，发送后可以展开查看注释。
- 后续消息使用 localStorage 保存并监听 storage 事件，同一浏览器的标签页可以更新；刷新不会清空。尚未接入真实登录身份、服务端多人同步或 AI 回复。
- 浏览器验证：Word 分享入口初始上下文、发送与刷新保留、跨标签实时更新、Markdown 文件隔离、HTML 原有上下文保留；JS 语法检查通过。
